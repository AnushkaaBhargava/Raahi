# Raahi ✈️

Raahi is a travel discovery platform designed for people who enjoy exploring unique and less-explored destinations beyond mainstream tourist spots.

Built during the SmartBU Hackathon, the platform helps users discover hidden travel locations and plan memorable experiences.

## Features

* Explore offbeat travel destinations
* Destination information and recommendations
* User-friendly travel interface
* Responsive web design

## Tech Stack

* HTML
* CSS
* JavaScript

## Purpose

The goal of Raahi is to encourage travelers to discover lesser-known places and promote unique travel experiences.
